# 绍兴照片智能 AI 质检与重复性排查系统

基于 Python GUI（CustomTkinter 现代桌面界面）与火山引擎方舟多模态视觉大模型（`doubao-seed-2.0-lite`），专用于大规模现场采集照片的真实性质检与重复欺诈排查。

---

## 一、 系统架构与核心能力

### 1. 双核质检模式
- **模式一：相同照片 AI 抽检比对（成对初筛复核）**
  - 读取哈希预筛清单（如 10 万+ 行 Excel），自动匹配本地两两成对的照片。
  - **前置物理遮蔽水印（底部 20%）**：内存级别对动态软件水印（时间、GPS、任务编号）进行黑色遮蔽，彻底消除水印噪点干扰，只比对原始物理底片。
  - **店招文字独立解耦**：分别 OCR 提取图 1 与图 2 的店招名称，支持“完全一致”、“不一致”、“不涉及(无店招/室内)”三种状态。
  - **多维证据链互证**：量化输出场景物理重合度（0.0 ~ 1.0），综合相机视角、光影走向、偶发微小物件（车辆、海报、花架）与拍摄瑕疵判定是否为同一张底片。
  - **原表追加副本生成**：100% 保留原有 10 万行原始数据与 34 列字段不变，在最右侧追加 10 列 AI 详细多维证据结果。
- **模式二：真实门头照单图智能识别**
  - 自动审查单张采集照片是否为真实门头招牌，识别翻拍屏幕、打印纸张、伪造假门头、室内违规拍摄等风险。
  - 提取招牌商户名称，输出可信度与核验原因。

### 2. 前端 Prompt Studio（提示词可视化与热调优）
- 界面内嵌提示词工作台，支持直接查看与修改当前送入大模型的提示词逻辑。
- 支持即时生效与一键恢复默认，方便不同项目针对特定业务场景灵活定制审查标准。

### 3. 统计学科学抽样引擎
- **AQL 工业质检抽样（推荐）**：遵循 GB/T 2828.1 / ISO 2859-1 一般检验水平 II 抽样表，兼顾审计效能与代表性。
- **统计学 95% 置信度抽样**：基于有限总体方差公式计算精确样本量。
- **分层随机抽样（Stratified Sampling）**：按候选组分层随机抽取，避免同类数据扎堆。

## 二、 文件结构说明

```text
├── app.py                             # 现代桌面 GUI 主应用程序 (CustomTkinter)
├── ai_client.py                       # 火山引擎视觉大模型客户端 (Base64编码/前置水印遮蔽/多维证据链)
├── data_processor.py                  # Excel 数据解析、本地图片高效索引与原表副本追加导出引擎
├── sampling.py                        # AQL 与统计学 95% 置信度抽样算法
├── evaluate_20_pairs.py               # 真实 20 组分层抽检离线评估与测试脚本
├── photo_duplicate_scanner_gui.py     # 基于感知哈希 (pHash/dHash/aHash) 的初筛对比工具
├── photo_review_builder_gui.py        # 人工审核与复核工作台
├── batch_download_photos_python.py    # OSS/URL 照片多线程批量下载脚本
├── run_ai_checker.command             # macOS 访达双击一键启动脚本
├── photo_export_v5-合并.sql           # SQL 导数与合并数据脚本
├── photo_export_v5-分表.sql           # SQL 分表导数脚本
├── test_photos/                       # 本地轻量级重复测试样例图片
├── test_storefront_photos/            # 本地轻量级门头测试样例图片
├── 20组AI抽检评估报告.xlsx             # 20 组实测评估多维证据 Excel 报告
└── .gitignore                         # Git 忽略配置 (已自动排除几十GB海量照片与大表格)
```
